Quick start

  1. Open the tab with your contacts (header in row 1).
  2. Extensions → Dedupe Pilot → Open Dedupe Pilot.
  3. Check the detected columns, pick strictness, click Find & merge duplicates.
  4. Review the new tabs: DP Clean (one row per contact), DP Review (pairs to check), DP Report (which rows merged and why), DP Invalid.

Matching rules

  • Same valid email and compatible names → merge.
  • Same phone → merge only if name or company also agree (shared office lines are common).
  • Similar name (+ company) → merge above the strictness threshold, slightly below goes to Review.
  • Two different valid personal emails are never merged automatically.

Limits

Free: 500 rows per run (first 500 rows previewed). Pro: 25,000 rows per run. Very large tabs can take up to a few minutes.
